# C++ File Organizer

A command-line file organization tool written in C++17.

## Goals

- Scan files in a specified directory.
- Classify files by extension.
- Preview planned changes without modifying files.
- Move files only after explicit confirmation.

## Tech Stack

- C++17
- std::filesystem
- CMake
